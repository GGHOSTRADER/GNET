TS PROJECT

11 Data points send from Tradestation to Python server through TCP using .dll file created in c++

Data:
1)Symbol
2)Date
3)Time
4)Open
5)High
6)Low
7)Close
8)Up
9)Down
10)Vwap
11)Bar Number

Data exported from Tradestation into Python server Through TCP
----------------------------------------------------------------------
1) Symbol:
Ticker Symbol
Value Type: String pointer
Calculation = None
Invariants = symbol != null , symbol type == string

2) Date: 
Date in YYMMDD
Value type = Interger
Calculation = Ts uses a propietary interger version which is 1900 the starting point YYYMMDD where YYY = years since 1900
Example =  April 12 of 1999 = 990412
Invariants =  date > 1260000 , 12 >= MM >= 1 , 31 >= DD >= 1,

3) Time in Seconds:
Extracting current time of the day since midnight, comes in seconds
Value type = Interger
Calculation =
HOUR 0 == Midnight
HOUR * 3600 = X
MINUTE * 60 = Y
SECOND * 1 = Z
TOTAL SECONDS = X + Y + Z

4) Open:
Price at which this bar started trading
Value type = Double
Calculation = None
Invariant = Open > 0 , Open isinstance float

5) High:
Highest Price traded in the trading interval
Value type = Double
Calculation = None
Invariant = Open <= High & High != 0 , High type isinstance float

6) Low:
Low Price traded in the trading interval
Value type = Double
Calculation = None
Invariant = Open >= Low & Low != 0, Low type isinstance float

7) Close:
Last price when the bar interval stopped trading
Value type = Double
Calculation = None
Invariant = Close >= Low & Close <= High & Close != 0 , Close type isinstance float

8) Up:
Meaning = Market Buy orders
Value type = Interger
Calculation = None
Invariant = Up >= 0 , Up type isinstance int

9) Down:
Meaning = Market Sell orders
Value type = Interger
Calculation = None
Invariant = Down >= 0 , Down isinstance int

10) Vwap:
Meaning = Volume Weighted Average Price since market Open
Value type = Double
Components = Volume: Sum of transactions (Up + Down), High: Highest price traded in the interval, Low: Lowest traded price in the interval, Close: Last traded price in the interval.	
Calculation = Sum(((high+low+close)/3)*(Up+Down)) / Sum(Up+Down)   {Not calculated here}
Invariant = vwap >= 0 , Vwap isinstance Float

11) Bar Number:
Meaning = Bar number Since the start of bar
Value type = Interger
Calculation = None
Invariant = bar_number[x] > bar_number[x-1] , barnumber != -n , Bar Number type isinstance int
